# Wanderer 1.4.5

### Changed
- New characters start from a ready-made setup, the one the author plays with: names when you come near, a quieter interface, gathering and quest objects shown, the action camera, your effects over time, automatic resurrection and summons outside raids. Accepting and handing in quests stays yours. Existing characters keep their settings, and every choice can be changed.
- The Immersion way of playing follows the same choices.

### Fixed
- The unit frames no longer ask the game, again and again in a fight, for a change it refuses on protected bars: it is done once the fight is over.
- With the game's controller interface on, the label follows the character the game is pointing at.
